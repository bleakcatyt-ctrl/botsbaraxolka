# Telegram-бот «Барахолка Воскресенск»

Полнофункциональный Telegram-бот для покупки, продажи и вывоза вещей в городе **Воскресенск, Московская область**.

## 🛠 Технологии:
- Node.js
- `node-telegram-bot-api`
- `sqlite3`
- `dotenv`

---

## ⚙️ Установка и запуск:

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Проверьте файл `.env` (он уже настроен с вашим токеном и городом):
   ```env
   BOT_TOKEN=8902220728:AAES9DngrpesTAMsdPOGh8dKiGr1sMIAJL8
   MAIN_ADMIN=@xzxzxzxzcz123
   CONTACT_ADMIN=@xzxzxzxzcz123
   CITY=Воскресенск
   REGION=Московская область
   ```
3. Запустите бота:
   ```bash
   npm start
   ```
